SwiftPieces is a free library (MIT + Commons Clause) of animated SwiftUI components built around iOS 26 Liquid Glass and Metal shaders, blocks built from them, and a curated taste of what SwiftPieces Pro offers in full: production-ready SwiftUI screens, more blocks, whole flows and complete app templates. Read [why SwiftPieces exists and how it is funded](/about).

## What earns a place

A piece is here because it saves an afternoon: the design, the motion, the gesture physics, the haptics and the states are already done. If a coding agent could produce it from a one-sentence prompt, it is not in the library. Every piece passes four tests: it is hard to recreate, it looks designed before it moves, a good developer would ship it, and its interaction is iPhone-first.

## What a piece is

- **One self-contained `.swift` file** named after its primary type, with a `#Preview`.
- **Apple frameworks only.** No third-party dependencies in the free library.
- **iOS 17 baseline.** Liquid Glass pieces target iOS 26 and gate every glass call with `#available(iOS 26, *)` plus a Material fallback.
- **Parameters, not forks.** Every piece is customized through init parameters with sensible defaults.
- **Accessible by default.** Dynamic Type, semantic colors, and respect for Reduce Motion and Reduce Transparency.

## What a block is

A block is a whole section of a screen built from pieces: a [sign-in form](/docs/blocks/auth/sign-in), an [account settings section](/docs/blocks/settings/account-settings), a [stats overview](/docs/blocks/analytics/stats-overview), a [checkout](/docs/blocks/commerce/checkout). The pieces inside carry the interaction, the motion and the haptics; the block lays them out, wires them together and gives them their states, so you drop it into a screen and connect it to your app with a closure or two.

- **One `.swift` file** named `<Name>Block`, plus the pieces it is built from, which it lists as dependencies. The CLI and the MCP server install them together.
- **Yours to change.** Like a piece, a block is plain SwiftUI in your project. Rearrange it, restyle it, or take the parts you need.
- **Free and Pro.** Free blocks use the house style of the pieces. SwiftPieces Pro's blocks are themed by its design system and re-skin with any of its families. [All blocks](/docs/blocks).

## Three ways to install

<Tabs items={["Copy", "CLI", "Agent"]}>
  <Tab value="Copy">Open any piece, copy the source, paste it into a file in your app target. Metal shaders copied alongside compile into your app's default library automatically.</Tab>
  <Tab value="CLI">`npx swiftpieces init` once, then `npx swiftpieces add SwipeDeck`. Files land in a `SwiftPieces/` synchronized folder, so Xcode 16+ picks them up with no project-file edits.</Tab>
  <Tab value="Agent">Point Claude Code, Cursor, or Xcode at the SwiftPieces MCP server and ask for a piece in plain English. The agent resolves it against the registry and installs it.</Tab>
</Tabs>

## Verified APIs only

Every Apple API in this library is checked against developer.apple.com and type-checked against the iOS 26 SDK in CI. Tutorials on the web invent modifiers like `.liquidGlassUltra`. Those do not exist, and you will never find them here.
