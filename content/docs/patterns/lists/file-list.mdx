The files section of a folder, project or storage screen. A storage card splits the used space by type, the toolbar sorts by name, date, size or kind and switches between list and grid, and Add opens the system file importer or photo picker. Uploads show progress and Cancel and land as files, and every file has Rename in place, Share, Move and a confirmed Delete.

Its SwiftUI source comes with SwiftPieces Pro: [File List in the Pro library](https://pro.swiftpieces.com/library/patterns/file-list).
