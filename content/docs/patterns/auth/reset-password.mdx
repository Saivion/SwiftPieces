Three steps on one card under a Step 1 of 3 track: the email and Send code, a six-digit code with a Resend countdown and a wrong-code error, and a new password with strong-password AutoFill, show and hide, rules that tick off and a confirm field. Each step runs your closure through working, done and failed, Back returns a step, and a done state ends on Sign in.
