The status section for an agent working in the background. It shows the state, a ticking clock, what the agent is doing now, a segmented step bar and the tokens and cost so far, with Pause, Resume and a confirmed Stop, and Notify me when done through the system permission. It settles into a summary with the outputs to open, or the reason and Retry when it fails.

Its SwiftUI source comes with SwiftPieces Pro: [Agent Run in the Pro library](https://pro.swiftpieces.com/library/patterns/agent-run).
