A small, inline record for the top of an assistant message. Folded it is one quiet row; opened, each call shows its symbol, name, argument summary and duration or status, and opens to its arguments and result as key and value pairs or monospaced JSON with Copy. It opens itself while calls run and folds once they finish.

Its SwiftUI source comes with SwiftPieces Pro: [Tool Calls in the Pro library](https://pro.swiftpieces.com/library/patterns/tool-calls).
