A composer pinned above the keyboard with a model pill whose menu describes each model and marks locked ones as Pro, mode chips that toggle, and a line of messages left that turns to the warning colour near the limit. At the limit the composer turns off and offers Upgrade; the app owns the model and modes through bindings.

Its SwiftUI source comes with SwiftPieces Pro: [Model Composer in the Pro library](https://pro.swiftpieces.com/library/patterns/composer-modes).
