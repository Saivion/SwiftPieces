The tabs sit in one floating capsule with the selected tab on a quiet pill, and a round search button stands beside it, the way iOS 26 apps place search. Tapping search folds the tabs into one round button showing the current tab and opens the button into a field with the keyboard up. The screen above shows recent searches, then your results as the query changes, and tapping the folded tab goes back.
