Select mode for a list or grid. A top bar takes the navigation bar's place with the count, Select all and Done, rows gain selection circles, and an action bar of Share, Move, Duplicate and Delete enables by count. Actions run your async closures with working shown in place, Delete confirms with the count, and a line confirms each result with Undo.

Its SwiftUI source comes with SwiftPieces Pro: [Selection Toolbar in the Pro library](https://pro.swiftpieces.com/library/patterns/selection-toolbar).
