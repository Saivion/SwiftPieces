/// A voice note player whose waveform is the scrubber, for voice messages, audio notes, journals and podcast clips.
///
/// One liquid glass control: a red play button joined to a glass capsule that holds the waveform and the time, with an
/// optional speed chip joined to its far end. Played bars are inked in the text colour and the rest stay muted, cut
/// exactly at the playhead, mid-bar. Touch the waveform and the playhead drops under the finger, the bars around it
/// rise, and a glass bubble with the time buds up out of the capsule and rides the finger; let go and it melts home
/// and `onSeek` fires once. A tap seeks too. While a finger is down the `time` you pass is ignored, so playback
/// updates never fight the scrub, and after the seek the playhead holds where you left it until your player catches
/// up. A vertical drag that starts on the waveform still scrolls an enclosing scroll view.
///
/// Playback is your app's: the piece never runs a clock of its own. Pass the player's `time` and `isPlaying`; between
/// your updates the playhead glides on at the current speed, so a timer that reports a few times a second still
/// draws smooth progress. `WaveformScrub.samples(from:count:)` reads the peaks of an audio file for `samples`, off
/// the main thread.
///
/// ```swift
/// @State private var player = VoiceNotePlayer(url: note.url)   // your AVAudioPlayer wrapper
/// @State private var samples: [Float] = []
///
/// WaveformScrub(samples: samples, duration: player.duration, time: player.time, isPlaying: player.isPlaying,
///               rate: $player.rate, onPlayPause: { player.toggle() }, onSeek: { player.seek(to: $0) })
///     .task { samples = (try? await WaveformScrub.samples(from: note.url)) ?? [] }
/// ```
///
/// - Parameters:
///   - samples: Loudness from 0 to 1, oldest first, any count: they are resampled to the bars that fit, the peak of each stretch when there are more samples than bars, smoothly in between when there are fewer, and scaled so the loudest reaches full height. Empty while the waveform loads: a quiet row of dots shimmers once a second in its place (they hold still under Reduce Motion), and seeking still works.
///   - duration: The note's length in seconds. Formats the times and maps the waveform to seconds. Zero (still unknown) draws the waveform but turns seeking off.
///   - time: Where your player is, in seconds. Ignored while a finger is on the waveform. After a seek the playhead holds at the seek until `time` arrives near it, or 1.5 seconds pass.
///   - isPlaying: Whether your player is playing. Swaps play for pause, and lets the playhead glide between your `time` updates at the current speed.
///   - rate: The playback speed. Shows a speed chip joined to the end of the capsule that cycles through `rates` on each tap; set your player's rate from it. `nil`, the default, hides the chip.
///   - rates: The speeds the chip cycles through, in order. Defaults to 1×, 1.5× and 2×.
///   - messages: The piece's copy: VoiceOver labels and the speed label. Defaults are localizable through your String Catalog; replace any line, for example `title` with "Message from Ines".
///   - style: Colours, the control's height and the bars' width and spacing. Defaults to the SwiftPieces house palette, adapting to light and dark, with red for the play button.
///   - onPlayPause: Called when play or pause is tapped (and on Space or a two-finger double tap in VoiceOver). Start or pause your player. When the note has finished (`time` at `duration`, not playing), the button shows replay and `onSeek(0)` is called first.
///   - onSeek: Called once when a scrub or tap ends, for each VoiceOver or arrow key step of 5 seconds, and with 0 before a replay, with the time in seconds to move your player to.

    public init(
        samples: [Float],
        duration: TimeInterval,
        time: TimeInterval,
        isPlaying: Bool,
        rate: Binding<Double>? = nil,
        rates: [Double] = [1, 1.5, 2],
        messages: Messages = .standard,
        style: Style = .standard,
        onPlayPause: @escaping () -> Void,
        onSeek: @escaping (TimeInterval) -> Void

        // Non-finite samples count as silence, and the loudest reaches full height.
        let clean = samples.map { $0.isFinite ? abs($0) : 0 }
        let loudest = clean.max() ?? 0
        self.levels = loudest > 0 ? clean.map { min($0 / loudest, 1) } : clean
        self.isLoading = samples.isEmpty
        self.duration = duration.isFinite ? max(duration, 0) : 0
        self.time = time.isFinite ? time : 0
        self.isPlaying = isPlaying
        self.rate = rate
        let speeds = rates.filter { $0.isFinite && $0 > 0 }
        self.rates = speeds.isEmpty ? [1] : speeds
        self.messages = messages
        self.style = style
        self.onPlayPause = onPlayPause
        self.onSeek = onSeek
    }

    /// The room above and below the bars inside the capsule.

    private var canSeek: Bool { isEnabled && duration > 0 }
    private var clamped: TimeInterval { min(max(time, 0), duration) }
    /// Played through to the end and stopped there: the button offers a replay.
    private var finished: Bool { duration > 0 && !isPlaying && scrub == nil && held == nil && time >= duration - 0.05 }
    /// The playhead glides on between `time` reports while playing and nothing holds it.
    private var gliding: Bool { isPlaying && scrub == nil && held == nil && duration > 0 }

    /// Where the playhead is drawn, from 0 to 1, at `date`.
    private func fraction(at date: Date) -> Double {
        guard duration > 0 else { return 0 }
        if let scrub { return scrub }
        if let held { return held }
        guard gliding else { return clamped / duration }
        // At most a second past the last report, so a player that stops reporting never runs away.
        let ahead = min(max(date.timeIntervalSince(reported.at), 0), 1) * speed
        return min(max(reported.time + ahead, 0), duration) / duration
    }

            }

        .fontWeight(.semibold)
        .dynamicTypeSize(...DynamicTypeSize.accessibility2)
        // Disabled, the red goes grey with the rest rather than washing out to pink.
        .saturation(isEnabled ? 1 : 0)
        .opacity(isEnabled ? 1 : 0.45)
        .sensoryFeedback(.impact(weight: .light), trigger: playTick)
        .sensoryFeedback(.selection, trigger: grabTick)
        .sensoryFeedback(.selection, trigger: rateTick)
        .sensoryFeedback(.impact(flexibility: .soft), trigger: edgeTick)
        .onAppear { reported = WaveformScrubReport(time: clamped, at: .now) }
        .onChange(of: time) { _, new in
            reported = WaveformScrubReport(time: min(max(new, 0), duration), at: .now)
            // The player has caught up with the seek: let the playhead follow it again.
            if let heldTarget, abs(new - heldTarget) <= max(0.6, speed) { release() }
        }
        .onChange(of: isPlaying) { _, _ in reported = WaveformScrubReport(time: clamped, at: .now) }
        // Another note in the same place: nothing held from the last one carries over.
        .onChange(of: duration) { _, _ in
            release()
            scrub = nil
        }
        .task(id: holdRun) {
            guard held != nil else { return }
            try? await Task.sleep(for: .seconds(1.5))
            guard !Task.isCancelled else { return }
            release()
        }
        .accessibilityElement(children: .contain)
        .accessibilityAction(.magicTap) { togglePlay() }
    }

    private func togglePlay() {
        guard isEnabled else { return }
        // A finished note plays again from the start: the playhead goes back at once, then the player starts.
        if finished { seek(to: 0, animated: true) }
        onPlayPause()
        playTick += 1
    }

    private var capsule: some View {
        TimelineView(.animation(paused: !gliding)) { context in
            let shown = fraction(at: context.date)
            HStack(spacing: 10 * grow) {
                if rtl { timeLabel(shown) }
                waveform(shown)
                if !rtl { timeLabel(shown) }
            }
            .padding(.leading, (rtl ? 16 : 18) * grow)
            .padding(.trailing, (rtl ? 18 : 16) * grow)

        .frame(maxWidth: .infinity, maxHeight: .infinity)

        .overlay {
            WaveformScrubTouchLayer(isEnabled: canSeek) { handle($0) }
                .accessibilityHidden(true)
        }
        .onGeometryChange(for: CGFloat.self) { $0.size.width } action: { capsuleWidth = $0 }
        .pieceLiquid(Capsule(), interactive: false)
        .accessibilityElement(children: .ignore)
        .accessibilityLabel(messages.title)
        .accessibilityValue(spokenPosition)
        .accessibilityAddTraits(isPlaying ? .updatesFrequently : [])
        .accessibilityAdjustableAction { direction in
            switch direction {
            case .increment: step(by: 5)
            case .decrement: step(by: -5)
            @unknown default: break
            }
        }
        // A hardware keyboard: the arrows step 5 seconds (in reading order), Space plays and pauses.
        .focusable(isEnabled)
        .onKeyPress(.rightArrow, phases: [.down, .repeat]) { _ in key(rtl ? -5 : 5) }
        .onKeyPress(.leftArrow, phases: [.down, .repeat]) { _ in key(rtl ? 5 : -5) }
        .onKeyPress(.space) {
            guard isEnabled else { return .ignored }
            togglePlay()
            return .handled
        }
    }

    /// The bars: muted, then the same bars inked and cut at the playhead, so the split falls mid-bar.
    private func waveform(_ shown: Double) -> some View {
        let span = WaveformScrubBars.span(width: waveFrame.width, bar: style.barWidth, spacing: style.barSpacing)
        let split = span.offset + span.used * CGFloat(shown)
        let bars = WaveformScrubBars(levels: levels, barWidth: style.barWidth, spacing: style.barSpacing, focus: focus, lift: lifted && !reduceMotion ? 1 : 0)
        // The playhead never animates under the finger or while it glides; a seek while paused lands on `value`.
        let landing: Animation? = scrub != nil || gliding ? nil : motion.value
        return ZStack(alignment: .leading) {
            bars.fill(style.unplayed)
            if isLoading && !reduceMotion { shimmer(bars) }
            bars.fill(style.played)
                .mask(alignment: .leading) {
                    Rectangle()
                        .frame(width: max(split, 0))
                        .animation(landing, value: split)
                }
        }
        // The bars rise under the finger and settle back with a little give.
        .animation(lifted ? motion.snap : motion.release, value: lifted)
        // Right to left, the note plays from the right.
        .scaleEffect(x: rtl ? -1 : 1)
        .padding(.vertical, waveInset)
        .frame(maxWidth: .infinity, maxHeight: .infinity)
        .onGeometryChange(for: CGRect.self) { $0.frame(in: .named(WaveformScrubSpace.capsule)) } action: { waveFrame = $0 }
        .accessibilityHidden(true)
    }

    /// While the waveform loads: a soft band of light passes along the dots once a second.
    private func shimmer(_ bars: WaveformScrubBars) -> some View {
        TimelineView(.animation(minimumInterval: 1 / 30)) { context in
            let period = 1.2
            let phase = context.date.timeIntervalSinceReferenceDate.truncatingRemainder(dividingBy: period) / 0.9
            GeometryReader { proxy in
                let band = max(proxy.size.width * 0.35, 40)
                let x = -band + (proxy.size.width + band) * CGFloat(min(phase, 1))
                bars.fill(style.played.opacity(0.55))
                    .mask(alignment: .leading) {
                        LinearGradient(colors: [.clear, .black, .clear], startPoint: .leading, endPoint: .trailing)
                            .frame(width: band)
                            .offset(x: x)
                            .opacity(phase <= 1 ? 1 : 0)
                    }
            }
        }
    }

    /// The time inside the capsule: the total at the start and at the end, the elapsed time otherwise. It keeps the
    /// width of the longest time, so the waveform never shifts as digits change.
    private func timeLabel(_ shown: Double) -> some View {

        let text = atStart || finished ? clock(duration, rounding: true) : clock(shown * duration)
        return ZStack(alignment: rtl ? .leading : .trailing) {
            Text(clock(duration, rounding: true)).hidden()

                .contentTransition(reduceMotion ? .opacity : .numericText(value: shown))
                .animation(scrub == nil ? motion.value : nil, value: text)
        }
        .font(.footnote.weight(.semibold).monospacedDigit())
        .dynamicTypeSize(...DynamicTypeSize.xxxLarge)
        .foregroundStyle(style.secondaryLabel)
        .lineLimit(1)
        .fixedSize()
        .accessibilityHidden(true)
    }

    /// The time at the finger, on a glass bubble that buds up out of the capsule above it on a liquid neck. Always in
    /// the hierarchy, shrunk to nothing between scrubs: glass inserted inside a scroll view would stay invisible until
    /// its first animation ends, which is the whole bud.
    private var timeBubble: some View {
        let present = buds.contains("time")
        let out = buds.isOut("time")
        let half = bubbleWidth / 2

    // MARK: Speed

    /// A small glass chip joined to the capsule's end. It keeps the width of the widest speed, so the waveform never
    /// moves, and its title morphs letter by letter.
    private func speedChip(_ rate: Binding<Double>) -> some View {
        Button { cycle(rate) } label: {
            ZStack {
                ForEach(rates, id: \.self) { Text(messages.rate($0)).hidden() }
                PieceMorphText(text: messages.rate(rate.wrappedValue), font: .subheadline.weight(.semibold).monospacedDigit())
            }
            // A speed reads the same in every language ("1.5×"), and the morph lays its letters out one by one.

            // Grows to the largest standard size, so the waveform keeps its room at accessibility sizes.

            .lineLimit(1)

        }

        .accessibilityLabel(messages.speed)
        .accessibilityValue(messages.rateValue(rate.wrappedValue))
    }

    /// The next speed in `rates` after the current one, wrapping round.
    private func cycle(_ rate: Binding<Double>) {
        let now = rate.wrappedValue
        let next = rates.firstIndex { abs($0 - now) < 0.001 }.map { rates[($0 + 1) % rates.count] } ?? rates.first { $0 > now } ?? rates[0]
        withAnimation(motion.morph) { rate.wrappedValue = next }
        // The glide restarts from here at the new speed.
        reported = WaveformScrubReport(time: fraction(at: .now) * duration, at: .now)
        rateTick += 1
    }

    // MARK: Scrub

    private func handle(_ touch: WaveformScrubTouch) {
        switch touch {
        case .press(let x): grab(at: x)
        case .move(let x): drag(to: x)
        case .end(let x, let tapped): lift(at: x, tapped: tapped)
        case .cancel: abandon()
        }
    }

    /// The finger lands: the playhead drops under it at once, the bars around it rise and the time buds out.
    private func grab(at x: CGFloat) {
        guard canSeek else { return }
        let value = position(at: x)
        held = nil
        heldTarget = nil
        scrub = value
        fingerX = x
        bubbleSeconds = value * duration
        focus = splitX(value)
        atEdge = value <= 0 || value >= 1
        lifted = true
        grabTick += 1
        Task { await buds.bloom(["time"], reduceMotion: reduceMotion) }
    }

    /// Under the finger, never animated. A soft tick when it reaches either end.
    private func drag(to x: CGFloat) {
        guard scrub != nil else { return }
        let value = position(at: x)
        scrub = value
        fingerX = x
        bubbleSeconds = value * duration
        focus = splitX(value)
        let edge = value <= 0 || value >= 1
        if edge && !atEdge { edgeTick += 1 }
        atEdge = edge
    }

    /// The finger lifts: one seek, and the bubble melts home. A quick tap that never showed the scrub seeks too.
    private func lift(at x: CGFloat, tapped: Bool) {
        guard canSeek else { return abandon() }
        let value = position(at: x)
        let live = scrub != nil
        scrub = nil
        if tapped { grabTick += 1 }
        seek(to: value * duration, animated: !live)
        settle()
    }

    /// The system took the touch (a scroll began, a call came in): nothing is sought, the playhead goes back.
    private func abandon() {
        guard scrub != nil else { return }
        scrub = nil
        settle()
    }

    private func settle() {
        lifted = false
        Task { await buds.gather(["time"], reduceMotion: reduceMotion) }
    }

    /// Sends one seek and holds the playhead there until the player's `time` catches up with it.
    private func seek(to seconds: TimeInterval, animated: Bool) {
        guard duration > 0 else { return }
        let target = min(max(seconds, 0), duration)
        if animated {
            withAnimation(motion.value) { held = target / duration }
        } else {
            held = target / duration
        }
        heldTarget = target
        holdRun += 1
        onSeek(target)
    }

    /// Lets the playhead follow the player's `time` again.
    private func release() {
        guard held != nil || heldTarget != nil else { return }
        reported = WaveformScrubReport(time: clamped, at: .now)
        held = nil
        heldTarget = nil
    }

    /// A VoiceOver or keyboard step, from wherever the playhead is.
    private func step(by seconds: TimeInterval) {
        guard canSeek else { return }
        seek(to: fraction(at: .now) * duration + seconds, animated: true)
    }

    private func key(_ seconds: TimeInterval) -> KeyPress.Result {
        guard canSeek else { return .ignored }
        step(by: seconds)
        return .handled
    }

    /// The playhead, from 0 to 1, for a finger at `x` in the capsule's coordinates.
    private func position(at x: CGFloat) -> Double {
        let span = WaveformScrubBars.span(width: waveFrame.width, bar: style.barWidth, spacing: style.barSpacing)
        guard span.used > 0 else { return 0 }
        let local = rtl ? waveFrame.maxX - x : x - waveFrame.minX
        return Double(min(max((local - span.offset) / span.used, 0), 1))
    }

    /// Where the playhead falls in the waveform's own (unmirrored) coordinates.
    private func splitX(_ value: Double) -> CGFloat {
        let span = WaveformScrubBars.span(width: waveFrame.width, bar: style.barWidth, spacing: style.barSpacing)
        return span.offset + span.used * CGFloat(value)
    }

    // MARK: Time

    /// `0:42`, or `1:12:30` for an hour or more.
    private func clock(_ seconds: TimeInterval, rounding: Bool = false) -> String {
        let whole = max(0, rounding ? seconds.rounded() : seconds.rounded(.down))
        let pattern: Duration.TimeFormatStyle.Pattern = duration >= 3600 ? .hourMinuteSecond : .minuteSecond
        return Duration.seconds(Int64(whole)).formatted(.time(pattern: pattern))
    }

    /// "12 seconds of 42 seconds", for VoiceOver.
    private var spokenPosition: String {
        let current = (scrub ?? held).map { $0 * duration } ?? clamped
        let spoken: (TimeInterval) -> String = { seconds in
            Duration.seconds(Int64(max(0, seconds.rounded(.down)))).formatted(.units(allowed: [.hours, .minutes, .seconds], width: .wide))
        }
        return messages.position(spoken(current), spoken(duration.rounded()))
    }
}

/// Every bar of the waveform as one path: resampled to the bars that fit, centred on the line, at least a dot tall.
/// The bars near `focus` rise by up to 30% as `lift` goes to 1.
private struct WaveformScrubBars: Shape {
    var levels: [Float]
    var barWidth: CGFloat
    var spacing: CGFloat
    var focus: CGFloat
    var lift: CGFloat

    nonisolated var animatableData: CGFloat {
        get { lift }
        set { lift = newValue }
    }

    /// How many bars fit, how far in the first one starts (the leftover, split evenly) and the width they take.
    nonisolated static func span(width: CGFloat, bar: CGFloat, spacing: CGFloat) -> (count: Int, offset: CGFloat, used: CGFloat) {
        guard width >= bar, bar > 0 else { return (0, 0, 0) }
        let count = max(Int(((width + spacing) / (bar + spacing)).rounded(.down)), 1)
        let used = CGFloat(count) * bar + CGFloat(count - 1) * spacing
        return (count, (width - used) / 2, used)
    }

    /// The level of bar `index` of `count`: the peak of its stretch of samples, or between two samples when there are
    /// fewer samples than bars.
    nonisolated static func level(_ index: Int, of count: Int, in levels: [Float]) -> CGFloat {
        let n = levels.count
        guard n > 0, count > 0 else { return 0 }
        if n >= count {
            let lower = index * n / count
            let upper = max((index + 1) * n / count, lower + 1)
            var peak: Float = 0
            for i in lower..<min(upper, n) { peak = max(peak, levels[i]) }
            return CGFloat(peak)
        }
        guard count > 1, n > 1 else { return CGFloat(levels[0]) }
        let place = Double(index) * Double(n - 1) / Double(count - 1)
        let below = Int(place.rounded(.down))
        let above = min(below + 1, n - 1)
        let t = Float(place - Double(below))
        return CGFloat(levels[below] + (levels[above] - levels[below]) * t)
    }

    nonisolated func path(in rect: CGRect) -> Path {
        let span = Self.span(width: rect.width, bar: barWidth, spacing: spacing)
        var path = Path()
        guard span.count > 0 else { return path }
        // At rest the tallest bar leaves room to rise 30% inside the rect.
        let tallest = rect.height / 1.3
        let reach = (barWidth + spacing) * 5
        for i in 0..<span.count {
            let x = rect.minX + span.offset + CGFloat(i) * (barWidth + spacing)
            var h = barWidth + (tallest - barWidth) * Self.level(i, of: span.count, in: levels)
            if lift > 0 {
                let distance = abs(x + barWidth / 2 - focus)
                if distance < reach { h *= 1 + 0.3 * lift * (1 + cos(.pi * distance / reach)) / 2 }
            }
            let bar = CGRect(x: x, y: rect.midY - h / 2, width: barWidth, height: h)
            path.addRoundedRect(in: bar, cornerSize: CGSize(width: barWidth / 2, height: barWidth / 2), style: .continuous)
        }
        return path
    }
}

/// One finger on the waveform. It shows the press at once, or after a short wait inside a scroll view so a scroll
/// never flashes the scrub; it begins on a sideways move, fails on a vertical one, and a lift before either is a tap.
private final class WaveformScrubRecognizer: UIGestureRecognizer {
    var onTouch: ((WaveformScrubTouch) -> Void)?
    private var tracked: ObjectIdentifier?
    private var start: CGPoint = .zero
    private var pressed = false
    private var waiting: Task<Void, Never>?

    override func touchesBegan(_ touches: Set<UITouch>, with event: UIEvent) {
        super.touchesBegan(touches, with: event)
        // A second finger changes nothing once one is tracked; two at once are not a scrub.
        guard tracked == nil else { return }
        guard touches.count == 1, let touch = touches.first, let view else { return fail() }
        tracked = ObjectIdentifier(touch)
        start = touch.location(in: view)
        if insideScrollView {
            waiting = Task { @MainActor [weak self] in
                try? await Task.sleep(for: .milliseconds(110))
                guard let self, !Task.isCancelled, self.state == .possible, !self.pressed else { return }
                self.press()
            }
        } else {
            press()
        }
    }

    override func touchesMoved(_ touches: Set<UITouch>, with event: UIEvent) {
        super.touchesMoved(touches, with: event)
        guard let touch = touches.first(where: { ObjectIdentifier($0) == tracked }), let view else { return }
        let point = touch.location(in: view)
        switch state {
        case .possible:
            let dx = point.x - start.x, dy = point.y - start.y
            if abs(dx) >= 6, abs(dx) > abs(dy) {
                waiting?.cancel()
                if !pressed { press() }
                state = .began
                onTouch?(.move(point.x))
            } else if abs(dy) >= 8 {
                fail()
            }
        case .began, .changed:
            state = .changed
            onTouch?(.move(point.x))
        default:
            break
        }
    }

    override func touchesEnded(_ touches: Set<UITouch>, with event: UIEvent) {
        super.touchesEnded(touches, with: event)
        guard let touch = touches.first(where: { ObjectIdentifier($0) == tracked }), let view else { return }
        waiting?.cancel()
        let x = touch.location(in: view).x
        switch state {
        case .possible:
            onTouch?(.end(x, tapped: !pressed))
            state = .ended
        case .began, .changed:
            onTouch?(.end(x, tapped: false))
            state = .ended
        default:
            break
        }
    }

    override func touchesCancelled(_ touches: Set<UITouch>, with event: UIEvent) {
        super.touchesCancelled(touches, with: event)
        guard touches.contains(where: { ObjectIdentifier($0) == tracked }) else { return }
        waiting?.cancel()
        if pressed { onTouch?(.cancel) }
        state = state == .possible ? .failed : .cancelled
    }

    override func reset() {
        super.reset()
        waiting?.cancel()
        waiting = nil
        tracked = nil
        pressed = false
    }

    private func press() {
        pressed = true
        onTouch?(.press(start.x))
    }

    private func fail() {
        waiting?.cancel()
        if pressed { onTouch?(.cancel) }
        pressed = false
        state = .failed
    }

    /// Whether a scroll view holds this one, so a press waits a beat to see if the finger is scrolling.
    private var insideScrollView: Bool {
        var next = view?.superview
        while let current = next {
            if let scroll = current as? UIScrollView, scroll.isScrollEnabled { return true }
            next = current.superview
        }
        return false
    }
}

// MARK: - Reading a file

extension WaveformScrub {
    /// The waveform of an audio file, for `samples`: the peak of each of `count` equal stretches of the file, scaled so
    /// the loudest is 1.
    ///
    /// Reads and decodes the file in chunks on a background thread, never the main actor, so a long recording doesn't
    /// stall the interface; cancelling the calling task stops the read. Any format `AVAudioFile` opens works (m4a,
    /// caf, wav, mp3). A silent file returns zeros; an empty one returns an empty array.
    ///
    /// ```swift
    /// .task(id: note.url) { samples = (try? await WaveformScrub.samples(from: note.url)) ?? [] }
    /// ```
    ///
    /// - Parameters:
    ///   - url: A local audio file.
    ///   - count: How many samples to return. 160 is plenty for a phone-width waveform; the view resamples to the bars that fit.
    nonisolated public static func samples(from url: URL, count: Int = 160) async throws -> [Float] {
        guard count > 0 else { return [] }
        let read = Task.detached(priority: .utility) { try WaveformScrubReader.peaks(of: url, count: count) }
        return try await withTaskCancellationHandler {
            try await read.value
        } onCancel: {
            read.cancel()
        }
    }
}

private enum WaveformScrubReader {
    nonisolated static func peaks(of url: URL, count: Int) throws -> [Float] {
        let file = try AVAudioFile(forReading: url)
        let format = file.processingFormat
        let total = file.length
        guard total > 0, count > 0 else { return [] }
        let chunk: AVAudioFrameCount = 32_768
        guard let buffer = AVAudioPCMBuffer(pcmFormat: format, frameCapacity: chunk) else { return [] }
        let buckets = Int64(count)
        var peaks = [Float](repeating: 0, count: count)
        var position: Int64 = 0
        while position < total {
            try Task.checkCancellation()
            try file.read(into: buffer, frameCount: AVAudioFrameCount(min(Int64(chunk), total - position)))
            let frames = Int(buffer.frameLength)
            guard frames > 0, let channels = buffer.floatChannelData else { break }
            var i = 0
            while i < frames {
                // The bucket this frame falls in, and how many of the chunk's frames are still in it.
                let frame = position + Int64(i)
                let bucket = min(frame * buckets / total, buckets - 1)
                let end = ((bucket + 1) * total + buckets - 1) / buckets
                let run = max(min(Int(end - frame), frames - i), 1)
                for c in 0..<Int(format.channelCount) {
                    var peak: Float = 0
                    vDSP_maxmgv(channels[c] + i, 1, &peak, vDSP_Length(run))
                    if peak > peaks[Int(bucket)] { peaks[Int(bucket)] = peak }
                }
                i += run
            }
            position += Int64(frames)
        }
        let loudest = peaks.max() ?? 0
        guard loudest > 0 else { return peaks }
        return peaks.map { min($0 / loudest, 1) }
    }
}

/// A house-palette colour that follows the interface style.
private func waveformScrubColor(light: UInt32, dark: UInt32) -> Color {
    Color(uiColor: UIColor { @Sendable traits in
        let hex = traits.userInterfaceStyle == .dark ? dark : light
        return UIColor(red: CGFloat((hex >> 16) & 0xFF) / 255, green: CGFloat((hex >> 8) & 0xFF) / 255, blue: CGFloat(hex & 0xFF) / 255, alpha: 1)
    })
}

// The SwiftPieces motion language: shared spring tokens and gesture physics, with the same values in every
// piece. Each piece carries a copy of only the parts it uses, so this file stands alone. Generated from
// registry/foundation/PieceMotion.swift in the SwiftPieces repo; edit it there, not here.
// swiftpieces-motion: 1.1.0 (core, pressMath)

/// The SwiftPieces motion language: five spring tiers, and a named role for every moment a piece moves,
/// each with its Reduce Motion substitute.
///
/// Build one from the environment, `PieceMotion(reduceMotion: reduceMotion)`, and pick the role that names
/// what just happened. Never animate the tracking of a finger: set gesture state directly in `onChanged`, so the
/// surface stays under the finger, and spring only the release.
private struct PieceMotion {
    var reduceMotion = false

    // Tiers. Overshoot and settle times are measured from rest with SwiftUI's Spring.
    /// No overshoot, 90% in about 90ms. A press arriving under the finger.
    static var tight: Spring { Spring(duration: 0.14, bounce: 0) }
    /// About 2.8% overshoot, 90% in about 140ms. Snapping to a detent, page or segment.
    static var responsive: Spring { Spring(duration: 0.32, bounce: 0.25) }
    /// About 8.4% overshoot. Visible give: a release, a return from past an edge, a drag settling home.
    static var elastic: Spring { Spring(duration: 0.42, bounce: 0.38) }
    /// About 15% overshoot. A resolved action landing. At most once per interaction.
    static var expressive: Spring { Spring(duration: 0.48, bounce: 0.48) }
    /// About 1.5% overshoot, unhurried. Opening large surfaces and ambient change.
    static var calm: Spring { Spring(duration: 0.5, bounce: 0.2) }

    /// Reduce Motion: settles become this short spring with no overshoot.
    private static var still: Animation { .spring(duration: 0.25, bounce: 0) }

    // Roles.
    /// Touch-down. Starts on the same frame and never bounces under the finger.
    var press: Animation { .spring(Self.tight) }
    /// The finger lifts off a pressed surface, which springs back through rest.
    var release: Animation { reduceMotion ? Self.still : .spring(Self.elastic) }
    /// A dragged thing comes to rest. With a gesture's velocity, use `settle(velocity:from:to:)` instead.
    var settle: Animation { reduceMotion ? Self.still : .spring(Self.elastic) }
    /// Lands on a detent, page or segment.
    var snap: Animation { reduceMotion ? Self.still : .spring(Self.responsive) }
    /// A number, a chart value or anything else people read moves to its new value. Never overshoots, so it
    /// never shows a value that isn't true.
    var value: Animation { reduceMotion ? Self.still : .spring(duration: 0.35, bounce: 0) }
    /// Comes back from past a limit: a pull beyond the edge, a value pushed against its bound.
    var rebound: Animation { reduceMotion ? Self.still : .spring(Self.elastic) }
    /// A shape or container changes size, corner radius or form, with a little give at the end.
    var morph: Animation { reduceMotion ? Self.still : .spring(duration: 0.4, bounce: 0.2) }
    /// Something appears, opens or expands. Opening is a little slower than closing.
    var reveal: Animation { reduceMotion ? .easeOut(duration: 0.2) : .spring(Self.calm) }
    /// Something leaves, closes or collapses. Quick and firm, out of the way.
    var dismiss: Animation { reduceMotion ? .easeIn(duration: 0.18) : .spring(duration: 0.3, bounce: 0.08) }
    /// A resolved action lands: a check, a sent state, a reaction.
    var success: Animation { reduceMotion ? .easeOut(duration: 0.24) : .spring(Self.expressive) }
    /// A refused action. Firm, no wobble; `pieceShake` adds the movement.
    var error: Animation { reduceMotion ? .easeOut(duration: 0.2) : .spring(Self.responsive) }
    /// Slow ambient change. Loops themselves stop under Reduce Motion: check `allowsAmbient`.
    var ambient: Animation { reduceMotion ? .easeInOut(duration: 0.3) : .spring(Self.calm) }

    /// Loops, drifts, idle breathing and parallax run only when this is true.
    var allowsAmbient: Bool { !reduceMotion }

    /// A moving transition, or a plain fade under Reduce Motion.
    func transition(_ transition: AnyTransition) -> AnyTransition {
        reduceMotion ? .opacity : transition
    }

    /// For content replaced inside a container that stays put (a label, a glyph, a count): the old content
    /// blurs out as the new one sharpens in. A fade under Reduce Motion.
    @MainActor var swap: AnyTransition {
        reduceMotion ? .opacity : AnyTransition(.blurReplace)
    }
}

extension PieceMotion {
    /// About `depth` points per edge, not a fixed percentage: an icon sinks to 0.92, a pill 0.95, a card 0.985.
    nonisolated static func pressScale(for size: CGSize, depth: CGFloat = 2.5) -> CGFloat {
        let side = (max(size.width, 1) * max(size.height, 1)).squareRoot()
        return min(max(1 - depth * 2 / side, 0.92), 0.985)
    }

    /// An anchor partway from the center toward the touch, so the press leans into the finger without tipping.
    nonisolated static func pressAnchor(touch: CGPoint?, in size: CGSize, lean: CGFloat = 0.6) -> UnitPoint {
        guard let touch, size.width > 0, size.height > 0 else { return .center }
        let x = min(max(touch.x / size.width, 0), 1)
        let y = min(max(touch.y / size.height, 0), 1)
        return UnitPoint(x: 0.5 + (x - 0.5) * lean, y: 0.5 + (y - 0.5) * lean)
    }
}

// MARK: - Piece liquid

// The SwiftPieces liquid glass language: glass shapes that merge through a neck, bubbles that bud out of
// and melt back into each other, and the frosted fallback before iOS 26. Each piece carries a copy of only
// the parts it uses, so this file stands alone. Generated from registry/foundation/PieceLiquid.swift in the
// SwiftPieces repo; edit it there, not here. The rules are in LIQUID_GLASS.md.
// swiftpieces-liquid: 1.8.0 (liquid, liquidPress, bud, morphText)

/// The liquid glass language: one merge distance, two rest gaps, and the springs a bubble leaves and comes home on.
///
/// Glass shapes inside one `PieceLiquidGroup` melt into each other through a neck when they come within `merge`
/// points. Parts of one control rest `joined`, inside that distance, so the neck holds; separate actions rest
/// `apart`, outside it, so they only goo while one buds out of, or melts back into, another.
private enum PieceLiquid {
    /// Glass shapes closer than this share a neck.
    static let merge: CGFloat = 20
    /// The gap between parts of one control (a stepper's buttons, a progress pill and its stop): the neck holds,
    /// short and smooth, about two thirds of the shapes' height at its waist. Joined parts read best at one height.
    static let joined: CGFloat = 4
    /// The gap between separate actions (menu items, confirm and cancel, chips): they rest as their own bubbles.
    static let apart: CGFloat = 26
    /// How far a bubble shrinks while it is home inside its parent.
    static let homeScale: CGFloat = 0.72

    /// A bubble leaving its parent: slow enough that the neck's stretch and snap read.
    static func split(reduceMotion: Bool) -> Animation {
        reduceMotion ? .easeOut(duration: 0.2) : .spring(duration: 0.62, bounce: 0.22)
    }

    /// A bubble going home. No bounce: a bounce would carry it out through the far side of its parent.
    static func home(reduceMotion: Bool) -> Animation {
        reduceMotion ? .easeIn(duration: 0.18) : .spring(duration: 0.5, bounce: 0)
    }
}

/// A group of glass shapes that merge into one liquid surface. On iOS 26 it is a `GlassEffectContainer`; before
/// that, and under Reduce Transparency, the shapes draw on their own and simply don't merge. `lift` adds the soft
/// shadow liquid glass floats on in light mode.
private struct PieceLiquidGroup<Content: View>: View {
    var spacing: CGFloat = PieceLiquid.merge
    var lift = true
    @ViewBuilder var content: Content
    @Environment(\.accessibilityReduceTransparency) private var reduceTransparency
    @Environment(\.colorScheme) private var colorScheme

    var body: some View {
        container
            .shadow(color: .black.opacity(lift && colorScheme == .light ? 0.07 : 0), radius: 18, y: 8)
    }

    @ViewBuilder private var container: some View {
        #if compiler(>=6.2)
        if #available(iOS 26, *), !reduceTransparency {
            GlassEffectContainer(spacing: spacing) { content }
        } else {
            content
        }
        #else
        content
        #endif
    }
}

/// One liquid glass shape: Liquid Glass on iOS 26, carrying `tint` as a solid colour and swelling under a press when
/// `interactive`; a frosted Material with a light rim and a soft shadow before that; a solid fill under Reduce
/// Transparency.
///
/// The tint is painted inside clear glass rather than tinting the glass. Tinted glass in a group bleeds its colour
/// through every neck as a smear, so a red button would glow into the white pill it is joined to; painted inside,
/// the colour stays crisp to the shape's edge, the necks between shapes are clear glass, and a tint change animates
/// like any colour (tinted glass snaps).
private struct PieceLiquidSurface<S: Shape>: ViewModifier {
    var shape: S
    var tint: Color?
    var interactive: Bool
    @Environment(\.accessibilityReduceTransparency) private var reduceTransparency
    @Environment(\.colorScheme) private var colorScheme
    @Environment(\.pieceLiquidScale) private var scale

    func body(content: Content) -> some View {
        #if compiler(>=6.2)
        if #available(iOS 26, *), !reduceTransparency {
            // Scaled as two parts, content and outline, about the same centre. A scaleEffect on a glass view inside a
            // GlassEffectContainer shrinks the glass but leaves what it carries full size, pinned to its corner.
            content
                .background { shape.fill(tint ?? .clear) }
                .scaleEffect(scale)
                .glassEffect(glass, in: shape.scale(scale))
        } else {
            fallback(content).scaleEffect(scale)
        }
        #else
        fallback(content).scaleEffect(scale)
        #endif
    }

    #if compiler(>=6.2)
    @available(iOS 26, *)
    private var glass: Glass {
        interactive ? Glass.regular.interactive() : .regular
    }
    #endif

    private func fallback(_ content: Content) -> some View {
        let dark = colorScheme == .dark
        return content
            .background {
                if reduceTransparency {
                    shape.fill(tint ?? (dark ? Color(white: 0.17) : Color(white: 0.97)))
                } else {
                    ZStack {
                        shape.fill(.regularMaterial)
                        if let tint { shape.fill(tint.opacity(0.88)) }
                    }
                }
            }
            .overlay { shape.stroke(Color.white.opacity(dark ? 0.14 : 0.7), lineWidth: 0.5) }
            .shadow(color: .black.opacity(dark ? 0.32 : 0.08), radius: 10, y: 5)
    }
}

private struct PieceLiquidScaleKey: EnvironmentKey {
    static let defaultValue: CGFloat = 1
}

private extension EnvironmentValues {
    /// How much the liquid shapes below are scaled, about their own centres. Nested scales multiply.
    var pieceLiquidScale: CGFloat {
        get { self[PieceLiquidScaleKey.self] }
        set { self[PieceLiquidScaleKey.self] = newValue }
    }
}

private extension View {
    /// Draws this view on a liquid glass `shape`. Put it inside a `PieceLiquidGroup` so it can merge with its neighbours.
    func pieceLiquid<S: Shape>(_ shape: S, tint: Color? = nil, interactive: Bool = true) -> some View {
        modifier(PieceLiquidSurface(shape: shape, tint: tint, interactive: interactive))
    }

    /// Scales the liquid glass shapes in this view, content and outline together, about their own centres. Use it
    /// instead of `scaleEffect` on a glass view (a press, a lift, a swell): inside a group a plain `scaleEffect` shrinks
    /// the glass but leaves its content full size and off centre. Animates like any other value.
    func pieceLiquidScale(_ scale: CGFloat) -> some View {
        transformEnvironment(\.pieceLiquidScale) { $0 *= scale }
    }
}

/// The press for a glass control: the same size-aware sink and lean as `piecePress`, applied through
/// `pieceLiquidScale` so the glass and what it carries sink together (a plain scaleEffect on glass leaves the content
/// behind). Put the glass inside what it presses: the label of a button, the view this modifies. Under Reduce Motion
/// it shades instead of moving.
private struct PieceLiquidPress: ViewModifier {
    let pressed: Bool
    var touch: CGPoint?
    var depth: CGFloat = 2.5
    @Environment(\.accessibilityReduceMotion) private var reduceMotion
    @Environment(\.colorScheme) private var colorScheme
    @State private var size: CGSize = .zero
    @State private var anchor: UnitPoint = .center

    func body(content: Content) -> some View {
        let motion = PieceMotion(reduceMotion: reduceMotion)
        let scale = pressed && !reduceMotion ? PieceMotion.pressScale(for: size, depth: depth) : 1
        // A scale about `anchor` is a scale about the centre plus this shift toward the anchor.
        let lean = CGSize(width: (anchor.x - 0.5) * size.width * (1 - scale), height: (anchor.y - 0.5) * size.height * (1 - scale))
        content
            .onGeometryChange(for: CGSize.self) { $0.size } action: { size = $0 }
            .brightness(pressed && reduceMotion ? (colorScheme == .dark ? 0.1 : -0.08) : 0)
            .pieceLiquidScale(scale)
            .offset(lean)
            .animation(pressed ? motion.press : motion.release, value: pressed)
            .onChange(of: pressed) { _, isPressed in
                if isPressed { anchor = PieceMotion.pressAnchor(touch: touch, in: size) }
            }
            .onChange(of: touch) { _, touch in
                if pressed, let touch { anchor = PieceMotion.pressAnchor(touch: touch, in: size) }
            }
    }
}

/// `PiecePressStyle` for glass buttons: the label (with its `.pieceLiquid` inside) sinks as one.
private struct PieceLiquidPressStyle: ButtonStyle {
    var depth: CGFloat = 2.5

    func makeBody(configuration: Configuration) -> some View {
        configuration.label.pieceLiquidPress(configuration.isPressed, depth: depth)
    }
}

private extension View {
    /// Sinks this view's glass while `pressed`, leaning toward `touch` (in this view's coordinates) when given.
    func pieceLiquidPress(_ pressed: Bool, touch: CGPoint? = nil, depth: CGFloat = 2.5) -> some View {
        modifier(PieceLiquidPress(pressed: pressed, touch: touch, depth: depth))
    }
}

/// The bud: how a bubble leaves and rejoins its parent, driven explicitly so every bubble shows the whole cycle.
///
/// A bubble is born at `home`, inside its parent, where the two glass shapes are one. It springs out to `rest`, and
/// while it is inside the merge distance a neck holds it to the parent, thinning as it goes, until it snaps free.
/// Going home it springs back on a spring with no bounce, the neck reaches out and re-forms, and only once it has
/// melted all the way in is it removed. Both offsets are relative to where the bubble is laid out. Under Reduce
/// Motion it stays at `rest`: its content fades and its glass closes in place.
private struct PieceBud: ViewModifier {
    var out: Bool
    var rest: CGSize
    var home: CGSize
    @Environment(\.accessibilityReduceMotion) private var reduceMotion

    func body(content: Content) -> some View {
        if reduceMotion {
            // No travel. Inside a group glass ignores opacity, so the glass closes to nothing in place on the short
            // Reduce Motion ease while its content fades; the opacity covers a bubble outside a group.
            content
                .pieceLiquidScale(out ? 1 : 0.001)
                .opacity(out ? 1 : 0)
                .offset(rest)
        } else {
            // The glass shrinks through `pieceLiquidScale`, never a plain scaleEffect (see there), then moves.
            content
                .pieceLiquidScale(out ? 1 : PieceLiquid.homeScale)
                .offset(out ? rest : home)
        }
    }
}

/// A bubble's own content, on its own clock: gone the moment the bubble heads home, so it never rides over the
/// parent's content, and arriving just after the bubble leaves.
private struct PieceBudContent: ViewModifier {
    var out: Bool

    func body(content: Content) -> some View {
        content
            .blur(radius: out ? 0 : 6)
            .opacity(out ? 1 : 0)
            .animation(out ? .easeOut(duration: 0.3).delay(0.1) : .easeOut(duration: 0.14), value: out)
    }
}

private extension View {
    /// Places a bubble at `rest` while `out`, and at `home` (inside its parent, shrunk) while not.
    func pieceBud(out: Bool, rest: CGSize = .zero, home: CGSize) -> some View {
        modifier(PieceBud(out: out, rest: rest, home: home))
    }

    /// Hides a bubble's icon or label while it is home. Put it on the content, inside the glass.
    func pieceBudContent(out: Bool) -> some View {
        modifier(PieceBudContent(out: out))
    }
}

/// Which bubbles exist and which are out. A bubble is added home with no animation, sent out on the next frame,
/// and called home before it is removed, so it always melts in rather than fading. Keep one in `@State`.
@MainActor @Observable
private final class PieceBuds {
    private(set) var present: [String] = []
    private(set) var out: Set<String> = []
    /// The latest call for each bubble. A bloom or gather that has been overtaken (a bubble sent home while it was
    /// still waiting to go out, or called out again while melting) leaves that bubble alone.
    @ObservationIgnored private var turn: [String: Int] = [:]

    func contains(_ id: String) -> Bool { present.contains(id) }
    func isOut(_ id: String) -> Bool { out.contains(id) }

    private func claim(_ ids: [String]) -> [String: Int] {
        var mine: [String: Int] = [:]
        for id in ids {
            let next = (turn[id] ?? 0) + 1
            turn[id] = next
            mine[id] = next
        }
        return mine
    }

    /// Puts bubbles straight out at rest with no motion: a view's first frame, or a state restored.
    func place(_ ids: [String]) {
        _ = claim(ids)
        var quiet = Transaction()
        quiet.disablesAnimations = true
        withTransaction(quiet) {
            for id in ids where !present.contains(id) { present.append(id) }
            out.formUnion(ids)
        }
    }

    /// Adds bubbles home, then sends each out, `stagger` seconds apart, after an optional `delay`.
    func bloom(_ ids: [String], reduceMotion: Bool, stagger: Double = 0.05, delay: Double = 0) async {
        let mine = claim(ids)
        var quiet = Transaction()
        quiet.disablesAnimations = true
        withTransaction(quiet) {
            for id in ids where !present.contains(id) { present.append(id) }
        }
        try? await Task.sleep(for: .milliseconds(24 + Int(max(delay, 0) * 1000)))
        let split = PieceLiquid.split(reduceMotion: reduceMotion)
        for (i, id) in ids.enumerated() where turn[id] == mine[id] {
            withAnimation(split.delay(reduceMotion ? 0 : Double(i) * stagger)) { _ = out.insert(id) }
        }
    }

    /// Calls bubbles home, last first, then removes them once they have melted in.
    func gather(_ ids: [String], reduceMotion: Bool, stagger: Double = 0.04) async {
        let mine = claim(ids)
        let home = PieceLiquid.home(reduceMotion: reduceMotion)
        for (i, id) in ids.reversed().enumerated() {
            withAnimation(home.delay(reduceMotion ? 0 : Double(i) * stagger)) { _ = out.remove(id) }
        }
        try? await Task.sleep(for: .milliseconds(Int((0.52 + Double(ids.count) * stagger) * 1000)))
        var quiet = Transaction()
        quiet.disablesAnimations = true
        withTransaction(quiet) { present.removeAll { ids.contains($0) && !out.contains($0) && turn[$0] == mine[$0] } }
    }
}

/// A label that changes letter by letter: letters both strings share hold still, the rest blur out and the new ones
/// blur in a few milliseconds apart. Under Reduce Motion it cross-fades. VoiceOver reads the whole string.
///
/// Only text whose letters stand on their own is cut into letters: Latin, Greek, Cyrillic, CJK, digits and symbols.
/// Those letters are laid out left to right whatever the layout direction, the order they read in, so "1.5×" stays
/// "1.5×" in an Arabic or Hebrew interface instead of coming out backwards. Text in a right-to-left script, or in one
/// whose letters join or reorder (Arabic, Hebrew, Devanagari, Thai and their neighbours), can't be cut apart without
/// breaking it, so it changes as one: the old string blurs out where it stood while the new one blurs in.
private struct PieceMorphText: View {
    var text: String
    var font: Font = .body.weight(.semibold)
    @Environment(\.accessibilityReduceMotion) private var reduceMotion

    var body: some View {
        // The morphing label at its full size when it fits. When it doesn't (a long label at an accessibility text
        // size, a narrow screen), the same words wrap onto a second line and shrink a little instead of running past
        // the screen's edge; that one changes as a whole rather than letter by letter. A single word never splits
        // across lines: it stays on one and shrinks further.
        let oneWord = !text.contains(where: \.isWhitespace)
        ViewThatFits(in: .horizontal) {
            morphing.fixedSize()
            Text(text)
                .lineLimit(oneWord ? 1 : 2)
                .multilineTextAlignment(.center)
                .minimumScaleFactor(oneWord ? 0.5 : 0.75)
                .fixedSize(horizontal: false, vertical: true)
                .id(text)
                .transition(transition(0, scale: 0.9))
        }
        .font(font)
        .accessibilityElement(children: .ignore)
        .accessibilityLabel(text)
    }

    @ViewBuilder private var morphing: some View {
        if Self.splits(text) {
            let glyphs = Array(text)
            HStack(spacing: 0) {
                ForEach(glyphs.indices, id: \.self) { i in
                    Text(String(glyphs[i]))
                        .id("\(i)\(glyphs[i])")
                        .transition(transition(i, scale: 0.6))
                }
            }
            // The letters' reading order, not the layout's: an HStack lays its children out backwards under a
            // right-to-left layout.
            .environment(\.layoutDirection, .leftToRight)
        } else {
            ZStack(alignment: .leading) {
                Text(text)
                    .id(text)
                    .transition(transition(0, scale: 0.9))
            }
        }
    }

    private func transition(_ i: Int, scale: CGFloat) -> AnyTransition {
        guard !reduceMotion else { return .opacity }
        return AnyTransition(.blurReplace(.downUp)).combined(with: .scale(scale: scale, anchor: .bottom))
            .animation(.spring(duration: 0.42, bounce: 0.3).delay(Double(i) * 0.022))
    }

    /// Whether `text` can be cut into letters that each read left to right on their own: no right-to-left script, no
    /// script that joins or reorders its letters, and no bidirectional control characters.
    private static func splits(_ text: String) -> Bool {
        !text.unicodeScalars.contains { scalar in
            switch scalar.value {
            case 0x0590...0x08FF, // Hebrew, Arabic, Syriac, Thaana, NKo, Samaritan, Mandaic
                 0x0900...0x0DFF, // Devanagari to Sinhala
                 0x0E00...0x0FFF, // Thai, Lao, Tibetan
                 0x1000...0x109F, // Myanmar
                 0x1780...0x17FF, // Khmer
                 0xA8E0...0xA8FF, // Devanagari Extended
                 0xFB1D...0xFDFF, // Hebrew and Arabic presentation forms
                 0xFE70...0xFEFF, // Arabic presentation forms B
                 0x200E...0x200F, 0x202A...0x202E, 0x2066...0x2069, // bidirectional marks, embeddings and isolates
                 0x10800...0x10FFF, // historic right-to-left scripts
                 0x1E800...0x1EFFF: // Adlam and other right-to-left scripts
                return true
            default:
                return false
            }
        }
    }
}

<PieceFacts name="WaveformScrub" />

A voice note player whose waveform is the scrubber, for voice messages, audio notes, journals and podcast clips. One liquid glass control: a red play button joined to a glass capsule that holds the waveform and the time, with an optional speed chip joined to its far end. Played bars are inked in the text colour and the rest stay muted, cut exactly at the playhead, mid-bar. Touch the waveform and the playhead drops under the finger, the bars around it rise, and a glass bubble with the time buds up out of the capsule and rides the finger; let go and it melts home and `onSeek` fires once. A tap seeks too. While a finger is down the `time` you pass is ignored, so playback updates never fight the scrub, and after the seek the playhead holds where you left it until your player catches up. A vertical drag that starts on the waveform still scrolls an enclosing scroll view. Playback is your app's: the piece never runs a clock of its own. Pass the player's `time` and `isPlaying`; between your updates the playhead glides on at the current speed, so a timer that reports a few times a second still draws smooth progress. `WaveformScrub.samples(from:count:)` reads the peaks of an audio file for `samples`, off the main thread. ```swift @State private var player = VoiceNotePlayer(url: note.url)   // your AVAudioPlayer wrapper @State private var samples: [Float] = [] WaveformScrub(samples: samples, duration: player.duration, time: player.time, isPlaying: player.isPlaying, rate: $player.rate, onPlayPause: { player.toggle() }, onSeek: { player.seek(to: $0) }) .task { samples = (try? await WaveformScrub.samples(from: note.url)) ?? [] } ```

## Notes

- One liquid glass control: a red play button joined to a glass capsule that holds the waveform and the time, and, when you pass `rate`, a smaller speed chip joined to the capsule's far end. Joined parts rest 4 points apart, so short liquid necks hold them together. Red appears only on the play button. On iOS 26 this is Liquid Glass; before that, a frosted material; under Reduce Transparency, solid fills.
- Playback is your app's. Pass your player's `time`, `duration` and `isPlaying`, start or pause it in `onPlayPause`, and move it in `onSeek`. The piece never runs a clock: between your updates the playhead glides on at the current speed for up to a second, so a periodic time observer or a timer that reports a few times a second still draws smooth progress, and a player that stops reporting never runs away.
- `samples` are loudness from 0 to 1, any count. They are resampled to the bars that fit the width (3 point bars, 2 points apart by default): the peak of each stretch when there are more samples than bars, smoothly in between when there are fewer. The loudest sample reaches full height and silence is a dot. Played bars are inked in the text colour and the rest stay muted, cut exactly at the playhead, mid-bar.
- Read `samples` from an audio file with `WaveformScrub.samples(from:count:)`: it decodes the file in chunks on a background thread (never the main actor), takes the peak of `count` equal stretches (160 by default) and scales them so the loudest is 1. Cancelling the calling task stops the read. Call it from `.task(id: url)` and store the result; it throws what `AVAudioFile` throws for a file it can't open.
- Touch the waveform and the playhead drops under the finger at once, the bars around it rise, and a glass bubble with the time buds up out of the capsule above the finger on a liquid neck and rides with it. Let go and the bubble melts home and `onSeek` fires once, with the time in seconds. A tap seeks too. Past either end the playhead stops at the start or the end with a soft tick. While a finger is down the `time` you pass is ignored, and after the seek the playhead holds where you let go until your `time` arrives near it (or 1.5 seconds pass), so it never jumps back while your player catches up.
- The bubble rises about 40 points above the control while a finger is down. Leave that room above it, or let it draw over what's there for that moment; at the very top of a scroll view, the scroll view's edge cuts it.
- Scrolling is never blocked. Touches come from a UIKit recognizer that begins on a sideways move and fails on a vertical one, and enclosing scroll views, sheets and the back swipe wait for it to fail. Inside a scroll view the press waits about a tenth of a second, so starting a scroll on the waveform never flashes the scrub.
- States: empty `samples` (the waveform is loading) shows a quiet row of dots with a soft light passing along them once a second (the dots hold still under Reduce Motion), and seeking still works. A `duration` of 0 (still unknown) turns seeking off. The time inside the capsule reads the total at the start and the elapsed time otherwise, in `0:42` form, or `1:12:30` from an hour; it keeps the width of the longest time, so the waveform never shifts. When the note has played to its end and stopped there, play turns to replay, and tapping it calls `onSeek(0)` and then `onPlayPause()`. Disabled (`.disabled(true)`), the control greys out, red included, and ignores touches.
- The speed chip cycles through `rates` (1×, 1.5× and 2× by default) on each tap, writing the `rate` binding with a selection tick, and its label morphs letter by letter. It keeps the width of the widest speed, so the waveform never moves, and its target is 44 points tall. Set your player's rate from the binding (`AVAudioPlayer.enableRate` must be on). Pass no `rate` for a plain voice note without the chip.
- Haptics: a light impact on play and pause, a selection tick when a finger grabs the waveform and when the speed changes, a soft tick when a scrub reaches the start or the end.
- VoiceOver: the play button reads Play, Pause or Play again. The waveform is one adjustable element labelled "Voice note" with a value such as "12 seconds of 42 seconds"; swipe up or down to move 5 seconds through `onSeek`. The speed chip is a button, "Playback speed", with a value such as "1.5 times" or "Normal". A two-finger double tap plays or pauses from anywhere on the control.
- Hardware keyboard: with the waveform focused, the arrow keys step 5 seconds (in reading order) and Space plays or pauses.
- Reduce Motion: the bars don't rise, the bubble fades in and out in place instead of budding, the glyph and digit changes cross-fade, and a seek while paused lands on a short spring with no overshoot.
- Dynamic Type: the text grows and the shapes follow it part way, up to 1.4 times, so the waveform keeps its room. The time inside the capsule and the speed stop growing at the largest standard size, the bubble at the first accessibility size. All text is one weight, semibold, with monospaced digits.
- Right to left: play stays on the leading side (now the right), the speed chip moves to the left, the bars play from the right and the time sits on the left of the capsule. The transport glyphs and the speed label are never mirrored.
- `Style` sets the play button's red and the glyph on it, the played and unplayed bars, the labels, the control's height (52 points, at least 44) and the bars' width and spacing. `Messages` replaces the VoiceOver labels, the speed label ("1.5×") and the position value ("12 seconds of 42 seconds"); every default goes through your String Catalog.
- Wire it to `AVAudioPlayer`: keep the player in an `@Observable` model, publish `currentTime` from a timer or `CADisplayLink` while playing, call `player.currentTime = seconds` in `onSeek`, set `player.rate` when `rate` changes, and set `isPlaying` false in `audioPlayerDidFinishPlaying`. For `AVPlayer`, read the time from `addPeriodicTimeObserver(forInterval:)` and seek with `seek(to:toleranceBefore: .zero, toleranceAfter: .zero)`.
