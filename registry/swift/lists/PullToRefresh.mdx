## Notes

- The piece owns its `ScrollView`, so the overscroll rubber-band is the system's own and nothing has to be faked. A zero-height ruler at the top of the content reports the overscroll through `onChange` on a named coordinate space rather than a `PreferenceKey`, because `onPreferenceChange` hands its value to a `@Sendable` closure and cannot touch view state under strict concurrency.
- The ring is drawn, not a system spinner: a faint track with a signal-red arc that draws from 12 o'clock as the pull deepens and winds up to 240°. At `style.threshold` (92pt) the gesture arms, the ring pops to 114% and a rigid impact fires; pulling back under the threshold disarms and the haptic is not repeated.
- Releasing an armed pull snaps the content down by `style.holdHeight` (64pt) and hands the rotation to a continuous spin while the arc shortens to a travelling segment. The held band is a real spacer in the scroll content, so the scroll extent stays honest while the spinner is up. Finishing plays a success haptic and springs the band closed.
- `onRefresh` is `async` and runs on the main actor, so it can touch `@State` directly and the spinner is held for exactly as long as the work takes. A refresh that returns instantly still holds for `style.minimumDuration` (0.6s) so it never flashes, and the task is cancelled if the view goes away.
- A long pull past the threshold keeps dragging the content but stops moving the ring, which parks at 1.3× the threshold. Below about a third of the threshold the ring is faded out, so it never pokes above the top edge.
- `Style` (`PullToRefresh.Style`, also `PullToRefreshStyle`): `accent`, `track`, `threshold`, `holdHeight`, `indicatorSize`, `lineWidth`, `minimumDuration`. The ring diameter scales with the body text size, so the indicator grows with Dynamic Type without any extra work.
- Reduce Motion keeps every state, replaces the springs with short fades and swaps the spin for a slow opacity pulse, so the held state still reads as "working" without rotation.
- VoiceOver cannot perform a pull, so `Refresh` is also a custom action on the container, and the held spinner is an element labelled "Refreshing" with the `updatesFrequently` trait. All user-facing strings go through `String(localized:)`.
