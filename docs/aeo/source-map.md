# Source map

Where an answer engine can learn about SwiftPieces, classified the way the AEO loop uses sources.

- **OWN.** We control the page. Fix the words here first.
- **CLAIM.** A profile we can create or edit, and we have not verified a listing.
- **EARN.** Someone else decides whether we are mentioned. Reddit counts as search: a thread can rank in Google and be quoted by an assistant.
- **CONTEST.** A source that answers the same question and may be cited instead of us.

**to-verify** means this pass did not confirm a listing. Do not treat it as listed. Do not treat it as absent beyond the checks named below.

Checked 2026-10-30 unless a row says otherwise. No star counts, download counts, or rankings.

## CONTEST

These sources answer overlapping questions. The job is a page of ours that is easy to cite beside them, not a claim that we outrank them.

| Source | Question they will keep answering | What we publish instead |
| --- | --- | --- |
| Apple's SwiftUI and Liquid Glass docs | What `glassEffect` and `GlassEffectContainer` are | `/docs/liquid-glass`: the fallback, the rules, and components that follow them. No invented APIs. |
| shadcn/ui docs | What shadcn is, for React | `/docs/choosing`: same copy-into-your-project idea, for SwiftUI. shadcn/ui stays React. |
| Other SwiftUI component repos and Swift Package Index pages | "Which package do I add?" | `/docs/installation` and `/docs/choosing`: SwiftPieces is copied source, not a package. Specific rival names were not audited. to-verify before naming one in public copy. |
| UIKit component libraries | Kits for UIKit apps | `/docs/choosing`: SwiftPieces is SwiftUI. No named UIKit kit until one is checked. |
| Tutorial blogs that show unofficial Liquid Glass modifiers | How to add glass quickly | The Liquid Glass guide names the failure mode (modifiers that do not exist) and the real APIs. |
| pro.swiftpieces.com | Price, screens, templates, Pro MCP | Linked from the choosing page, patterns, and the home FAQ. This repo does not describe Pro as open source and does not print a price. |

## What not to do with this map

- Do not add a badge, a star count, or a "featured on" line for a row marked to-verify.
- Do not buy mentions.
- A change on an OWN page ships in this repo. A CLAIM or EARN row is a decision for Saivion, outside this PR.
